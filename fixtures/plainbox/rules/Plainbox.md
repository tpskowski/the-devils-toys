# Plainbox

The smallest system the schema permits: what is required and nothing else.

Toybox declares everything optional a system may declare. Plainbox declares none
of it — no group page, no hirelings, no assets, no vices, no trait catalogue. It
exists so the application is tested against a system that leaves those out,
because "left out" and "empty" are different things and only one of them should
reach a player.

## Playing

One ability, one save. Roll d20 against Pluck; equal or under succeeds.
