# The Devil's Toys — GM's Guide

This is the guide for running a table. It assumes you have an account with the
**Game master** role; if you do not, whoever runs the server has to give you one
— see the [Admin's Guide](../admin/README.md).

Your players want the [Player's Guide](../README.md). Most of what is in there
is true for you too, so this guide covers the difference rather than repeating
it.

## Two places you work

Almost everything a GM does happens in one of two places, and knowing which is
which will save you hunting.

**The room** is where you run a session. It is the same screen your players see,
with more controls: setting the scene, revealing a handout, rolling behind the
screen, moving the clock, starting a fight.

**Room Config** is where you set the room up. It is a separate, wide screen at
its own address, opened from the rail's Manage section. It holds the things you
prepare rather than perform: the library, the cast, the room's own gear, the
calendar, the playlists, the party's hirelings.

The rule of thumb: **if it changes what the table sees right now, it is in the
room. If it changes what the room has available, it is in Room Config.** The
Library is the clearest example — you upload maps in Room Config and choose
which one is showing from the room.

Room Config opens in its own tab, so you can leave it open beside the game.

## What you cannot do

Two things belong to the server admin, not to you:

- **Deleting a room.** You can archive one, which is reversible; permanent
  deletion is admin-only.
- **Promoting anyone.** You can create player-level accounts, and nothing more.

There is also no way to hand your room to another GM from inside the
application. If you are stepping down, an admin has to do it — the path is in
[the admin guide](../admin/rooms.md#who-a-rooms-gm-is-and-how-that-changes).
